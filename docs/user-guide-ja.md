# もんじゃExcel参照トレーサーの使い方

参照元はデータを供給する側、参照先はデータを利用する側です。`入力!B5 → 集計!D10` は、集計!D10が入力!B5を使うことを表します。

「再解析」で現在のブックの数式を取得します。「検索対象ブックを追加」では、選択した保存済み.xlsx/.xlsmの数式・グラフ系列・ピボットソースを端末内で調べます。Office.js版は別の開いているブックを自動列挙しません。追加ファイルの×で対象から外せます。同名ファイルの重複追加はできません。

「全体の依存関係一覧」は直接参照を表示します。「選択セルの影響調査」は「調査するセル・範囲」で指定した場所に関係する参照を表示します。ブラウザーではファイル追加後にブックとシートを選び、B5やA1:C10などのセル・範囲を入力して「このセル・範囲を調査」を押してください。シート一覧には空のワークシートも表示します。「このセルを参照している場所」と「このセルが参照している場所」を選び、「間接参照も展開」で多段の参照を追えます。循環参照でも終了します。Excel内で利用する場合は、Excelの選択範囲を同じブック・シート・セル欄へ自動反映します。「Excelの選択セルを取得」でも反映できます。手入力後の方向切替は入力内容を維持し、次のExcel選択変更で新しい範囲へ更新します。

種類、指定ブック／対象ブックすべて、キーワードで絞り込めます。列見出しで並べ替え、見出しの端で幅を調整できます。Office.js版は100件ごとのページ表示です。進捗と経過秒数を表示し、「中止」で停止できます。完了済みの結果が残る場合があります。正常に再解析すると前回のライブ結果を置き換えます。

- 確定（confirmed）：静的に特定できた参照です。
- 推定（estimated）：動的な計算、スピルの開始位置、行依存のテーブル参照等に不確実性があります。
- 判定不能（unknown）：参照範囲を特定できません。選択セルの影響調査では一致として扱いません。全体一覧と注意事項も確認してください。

「移動 ←」で参照元、「移動 →」で参照先を開きます。Office.jsは現在のブック内のみ移動できます。別ブックはそのブックでアドインを開くか「場所をコピー」を使います。グラフの名前が不明な場合は配置シートまでの移動になります。グラフ専用シートには移動できない場合があります。ピボットの位置は左上セルで代表します。

「CSV出力」は現在の絞り込み結果をUTF-8 BOM付きで保存します。数式と解釈されうる項目には先頭にアポストロフィを追加します。上部の日本語／Englishで画面言語を切り替えます。

## 利用上の制限

Office.jsのライブ解析は数式のみです。グラフ・ピボットには保存ファイルを追加してください。保存後の変更はファイルの結果に含まれません。VBA、暗号化ファイル、xls、xlsbは対象外です。外部接続・データモデル・OLAPのセル範囲は特定できません。動的参照や複雑な名前・構造化参照には参照漏れ・過大検出が起こりえます。

編集後は再解析してください。選択変更は前回の結果を使い、全体を再走査しません。上限はファイル100 MiB、展開後256 MiB、XML単体64 MiB、参照50万件、ライブ解析の使用範囲1,000万セル／シート、間接参照10万件です。大きすぎるシートはスキップします。

VSTO版は、「検索対象ブック」で開く一覧から同じExcelインスタンスの検索対象をチェックします。「全体の依存関係一覧」「選択セルの影響調査」をリボンから開くと、必要に応じて解析を開始します。結果が0件の場合は、その旨と確認事項を結果表に表示します。注意事項は右下の「診断」で確認できます。取得できないExcel機能があっても、取得済みの参照は表示します。解析エラーは参照0件と区別して表示します。Excelで選択したセルの影響を両方向に調査できます。数式、埋め込みグラフ・グラフ専用シート、通常範囲やテーブルを使うピボットに対応します。標準VBAモードは保存済み.xlsm/.xlam/.xlsbを読み取り専用で解析します。未保存のコード変更と旧.xls形式は含みません。拡張モードは許可済みのVBProjectを読み取ります。AccessVBOM設定の変更・復元はExcelの設定画面で行ってください。アドインは設定を自動変更しません。保護されたプロジェクトは読み取りません。VBAの静的参照は実行時のブック・シートに左右されるため確定扱いにしません。コード位置は操作を表し、実行順序を表すものではありません。

調査対象のセル、数式、VBAを変更・実行しません。ファイルやコードを外部送信しません。CSVとコピーした場所にはブック名や数式が含まれるため、保存先と共有先に注意してください。
