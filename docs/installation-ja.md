# インストールと削除

## Office.js版・ブラウザーでのファイル解析

Node.js、ローカルサーバー、ユーザー証明書の追加は不要です。インターネットに接続できる対応ブラウザーで、[解析画面](https://excel.mnoda1979.chatgpt.site/trace/app/)を開いて利用します。

1. 製品ページの「ファイル解析を開く」を選びます。
2. 「検索対象ブックを追加」から保存済みの.xlsx/.xlsmを選択します。
3. 全体の依存関係を確認し、種類やキーワードで絞り込みます。影響調査ではブック・シートを選び、セル・範囲を入力して「このセル・範囲を調査」を押します。
4. 必要に応じてCSVを保存します。終了する場合はタブを閉じます。

選択ファイルの解析はブラウザー内で行います。ファイル内容を配信サーバーへ送信しません。画面とOffice.jsライブラリの読み込みには通信が必要です。未保存の変更、VBA、暗号化ファイル、xls、xlsbは対象外です。

配布ZIPには利用ガイド、公開HTTPS版のマニフェスト、解析画面へのショートカットが入っています。ZIPの展開だけでブラウザー解析を始められます。ソフトウェアや証明書をインストールする必要はありません。

## ExcelへOfficeアドインを追加する場合

Web版Excel（Excel for the web）、Excel JavaScript API 1.4以降、カスタムアドインの使用許可が必要です。画面は公開HTTPSサイトから読み込みます。利用者のPCにNode.jsを入れる必要はありません。

1. 製品ページからマニフェストXMLを保存します。
2. Excelのカスタムアドイン追加画面で、そのXMLを選択します。
3. 「もんじゃ参照トレーサー」からタスクペインを開きます。
4. 削除するときはExcelのアドイン管理から削除します。

追加方法と可否はExcelや組織の設定に依存します。個別追加が表示されない場合は管理担当者へお問い合わせください。組織の設定を無断で回避しないでください。Excel内での追加・移動操作は実機未確認です。ブラウザーでの保存ファイル解析と区別してください。

## VSTO版

Windowsデスクトップ版Excel、.NET Framework 4.8以降、VSTO Runtimeが必要です。Node.jsは不要です。64bit版Excelで動作を確認しています。32bit版Excelでの動作は未確認です。

1. Windows版のZIP全体を展開し、Excelを保存して終了します。
2. Setup.exeを起動し「インストール」を押します。管理者として実行する必要はありません。
3. 配布元を確認し、Officeの信頼確認で導入を許可します。この配布物は自己署名です。発行元の身元は第三者により確認されていません。
4. Excelを起動し「もんじゃ参照トレーサー」タブを開きます。

ユーザーフォルダーと現在のユーザーの登録情報を使います。既存のブックや他のアドインは削除しません。証明書を信頼されたルートに追加する必要はありません。Windows SmartScreenの警告や組織の制限がある場合は、配布元・管理担当者に確認してください。制限は自動変更しません。必要な前提ソフトの導入には管理者の対応が必要な場合があります。

削除するときはExcelを終了し、Windowsの「インストールされているアプリ」で本製品を削除するか、Setup.exeの「削除」を押してください。言語設定は保持されます。小さなセットアップ実行ファイルがユーザーフォルダーに残ります。

## 以前のローカル配信方式を利用していた場合

ローカル配信プロセスを終了してから、以前の配布物に含まれる削除スクリプトを使用してください。新しいブラウザー方式にはローカルサーバーや専用証明書は不要です。ブックのファイルを削除する必要はありません。
